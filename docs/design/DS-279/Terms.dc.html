Every status word, where it means two things, and the one word to use
Rule: one word, one meaning, everywhere Ben reads it: desk-q, notes, the digest, Jira. Internal queue names can stay if the screen never shows them.
Word todayWhat it means, and whereWhy it's unclearUse instead
donequeue: the worker opened its PR · DONE column: merged · Jira Done: should be mergedThree meanings. DS-215 showed Done in Jira while #233 was still open✓ Done = merged, and only that. Jira moves to Done on merge
parkedqueue: waiting for your answer, or held behind another ticketOne stored word for "you act" and "it moves by itself"Never on screen: ◆ Needs you or · Waiting
blocked / stuckdesk-q BLOCKED column (stuck in code): held by a Jira ticket outside the batch with a question openOnly you can unblock it, so it is needs you under another name◆ Needs you "blocked by DS-12, outside this batch: start anyway?"
waitingdesk-q: moves by itself · needs-you detail text: "waiting on you"The same word for opposite things· Waiting only when it moves by itself. Needs-you text says "needs your answer"
held / releaseheld = waiting behind a ticket · "release it" = let it start"Release" reads as shipping· Waiting · the command says "let it start"
queued / queuequeued: not triaged yet · the queue: every ticket in the batch · QUEUE DONE: when the batch finishesThree meanings○ Ready for untriaged too, detail "triaging" · column: ALL DONE BY
faileda worker gave up · a CI check failed · "fix failed"A ticket and a check share the word, and only the first needs you◆ Needs you "worker stopped: reason". "failed" only for checks
landing / merginglanding: PR open · "checks passed, merging" · here the merge also waits for youTwo words for one step. ◐ reads as halfway▸ Merging while checks run. Green and waiting for your OK: ◆ Needs you "merge it"
readydesk-q: waiting for a worker · GitHub: ready for review (undraft)Same word for a ticket and for a PR○ Ready for tickets only. For PRs say "undraft"
runninga worker · "checks running" · the supervisorOnly the first is a ticket state● Running for workers. Checks are "in progress", the supervisor is "on"
pass / passeda supervisor pass · checks passed"The last pass" sits next to "2 of 3 passed"Checks keep "passed". The supervisor's run gets its own word (open, see below)
